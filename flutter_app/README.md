# منصة المطورين - تطبيق Flutter للهواتف (Roblox Dev Store App)

تطبيق هاتف رسمي كامل مبني بتقنية **Flutter (Material 3)** باللغة العربية مع دعم كامل للاتجاه من اليمين لليسار (RTL) وثيم داكن عصري مستوحى من لغة روبلوكس ومجتمع المطورين.

---

## 🌟 ميزات تطبيق Flutter:

1. **شاشة بداية متحركة (Splash Screen):**
   - شعار تفاعلي نابض.
   - شريط تقدم ديناميكي.

2. **تسجيل الدخول وإنشاء الحساب:**
   - واجهة مخصصة للهواتف.
   - التحقق التلقائي من حسابات المطورين ومنح شارة التوثيق.

3. **شاشة الترحيب (Onboarding & Welcome):**
   - استعراض مزايا التطبيق وشارة المطور المعتمد (`Verified Dev ⚡`).

4. **شاشة ميزات الـ VIP الحصرية (خاصة بالتطبيق فقط):**
   - **صندوق الهدايا اليومي (Daily Robux Drops):** استلام رصيد Robux افتراضي وأكواد مجانية كل 24 ساعة.
   - **مسرّع ألعاب روبلوكس (Game Booster):** تقليل البينغ إلى 14ms وتوفير 65% من استهلاك بيانات الهاتف.
   - **خزينة الأكواد الحصرية (App Vault):** أكواد سرية قابلة للنسخ بنقرة واحدة لا تظهر في موقع الويب.
   - **إشعارات الألعاب والأكواد الفورية (Instant Push Alerts).**

5. **شاشة ألعاب روبلوكس وتحديثات المطورين:**
   - استعراض الألعاب وسجلات التحديثات الحية (Changelogs).
   - زر تشغيل مباشر للعبة في روبلوكس.

6. **متجر الأدوات والسكربتات والنماذج ثلاثية الأبعاد PBR.**

7. **شبكة الأصدقاء والمجتمع والدردشة المباشرة.**

8. **الملف الشخصي مع شارة المطور الموثق وشارة عضوية VIP الذهبية.**

---

## 🚀 تشغيل وبناء التطبيق:

### 1. تثبيت الحزم:
```bash
flutter pub get
```

### 2. تشغيل التطبيق في وضع التطوير:
```bash
flutter run
```

### 3. بناء ملف تثبيت الأندرويد (Release APK):
```bash
flutter build apk --release
```
يتم إنشاء ملف الـ APK في المسار:
`build/app/outputs/flutter-apk/app-release.apk`
