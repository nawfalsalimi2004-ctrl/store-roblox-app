# منصة ألعاب روبلوكس وتطبيقات المطورين (Roblox & Dev Store)

منصة وتطبيق متكامل مبني باللغة **React / TypeScript (TSX)** و **Tailwind CSS** مع تكامل **Firebase** ودعم كامل للغة العربية والاتجاه (RTL).

## 🌟 الميزات الرئيسية:
- **متجر ألعاب روبلوكس والتطبيقات الرقمية:** تصفح، فلترة، وسلة مشتريات وتحميل فوري.
- **سجلات التحديثات الحية (Changelogs):** متابعة أحدث الإصدارات وإضافات المطورين وتواريخها وإمكانية إطلاقها فورياً.
- **التحقق من حساب المطورين برمز البريد (Email OTP Verification):** نظام توثيق أمني متطور يرسل رمز تحقق من 6 أرقام لتأكيد الهوية.
- **صفحة البروفايل (Profile):** عرض بيانات المطور، حسابه على روبلوكس، ألعابه المنشورة، وإمكانية تعديل البيانات.
- **شبكة الأصدقاء (Friends):** قائمة الأصدقاء مع بيان حالة اللعب في روبلوكس، إرسال طلبات صداقة، ومراسلة مباشرة (Direct Chat).
- **الوضع المظلم والفاتح (Dark & Light Mode):** دعم التبديل السلس بين الوضعين المظلم والفاتح مع الحفظ التلقائي.
- **لوحة تحكم الإدارة (Admin Dashboard):** إدارة المستخدمين والمطورين، والتحكم في المنتجات والمقالات.
- **تكامل Firebase:** الربط مع خدمات فايربيس للمزامنة وحفظ البيانات.

## 🚀 التشغيل محلياً:
```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```
